# Reference status

Target: a well-maintained US 60 Hz Hammond B3 with Leslie 122.

Primary sources to transcribe and independently validate:
- https://synthmania.com/wp-content/uploads/2020/05/Hammond-Organ-B3-C3-Service-Manual.pdf
- https://www.hammondx66.com/wp-content/uploads/2022/09/Handy_Wiring_Guide_B3_C3.pdf

The current implementation is a *research prototype*, not an authentic Hammond emulator.
The 91-wheel frequency/gear table, shaft phase relationships, wiring, foldback,
complex tonewheel waveforms, pickup filtering, key contacts, percussion,
scanner vibrato, preamp, and Leslie model are NOT implemented or verified.

Do not fill unknown instrument parameters with undocumented assumptions.
