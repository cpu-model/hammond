# Pedal frequency table: source verification required

The 73-page B3/C3 service manual contains a B3/C3 schematic on PDF page 72 (zero-based page 71). The schematic labels eight contacts under a typical pedal key, pedal switch busbars, and generator terminals with the instruction SEE PEDAL WIRING CHART.

Searching the extracted text of that PDF for TABLE III did not locate the table previously claimed as the source of the 25-by-8 matrix in internal/registration/b3_pedal_harmonics.go. This does not prove the table is absent from image-only pages, but the claimed transcription has not been verified.

The current matrix therefore has **provisional** status. Neither its harmonic-frequency entries nor the contact-order and busbar mappings are authenticated by the available evidence. The source string and Verified boolean in PedalWiringEvidence are caller declarations, not independent proof.

Next: inspect the original pedal-and-frequency chart in the larger Hammond service manual, compare all 25 rows, and separately inspect the physical pedal switch chart. Record page numbers, model applicability and transcription checks before declaring factory accuracy.
